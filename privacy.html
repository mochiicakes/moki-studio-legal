Moki Studio Privacy Policy

Effective 20 November 2026 · Moki Studio · Terms of Service

What Moki Studio is

Moki Studio is a personal, non-commercial tool run by one person (the "operator"). It edits short videos and publishes them to the operator's own social media accounts, only after the operator approves each post. It is not offered to the public, and it does not connect to anyone else's accounts.

Accounts it connects to

Moki Studio connects only to accounts the operator owns:

  • Instagram (professional account) and a Facebook Page, through Meta's APIs
  • YouTube, through the YouTube Data API (YouTube API Services)
  • TikTok, through TikTok's Login Kit and Content Posting API

It uses these APIs to read basic profile information (account ID and name) and to upload and publish the operator's own videos with their captions. It does not read messages, followers' data or other people's content.

What it stores, and where

  • Login tokens for the accounts above, so it can post on the operator's behalf. They are kept on the operator's laptop and in the operator's private database (Supabase), never in public code.
  • Videos, captions and thumbnails the operator creates, stored on the operator's laptop and in private Cloudflare R2 storage.
  • Job records and cost logs (what was made, when, and how much the AI processing cost), stored in the operator's private Supabase database.

What it does not do

  • It does not collect personal data from anyone other than the operator.
  • It does not sell, rent or share data with anyone.
  • It does not use advertising, analytics or tracking.

Videos may be processed by service providers the tool depends on, only to do its job: Anthropic (Claude API) to help plan edits and write captions, Supabase for the database, and Cloudflare for file storage.

YouTube

Moki Studio uses YouTube API Services. By using its YouTube features you agree to the YouTube Terms of Service, and the Google Privacy Policy applies to data handled by Google. You can revoke Moki Studio's access to a Google account at any time at myaccount.google.com/permissions.

Data deletion

To disconnect an account and delete its data:

  1. Revoke access from the platform:
    • Instagram: Settings → Website permissions (Apps and websites) → remove Moki Studio
    • Facebook: Settings & privacy → Settings → Business integrations → remove Moki Studio
    • Google / YouTube: myaccount.google.com/permissions → Moki Studio → remove access
    • TikTok: Settings and privacy → Security → Apps and services permissions → remove Moki Studio
  2. Email mochii.shoutcast@gmail.com asking for deletion. Stored tokens, profile information, videos and logs for that account are deleted within 30 days, and you'll get a confirmation reply.

Tokens stop working as soon as access is revoked on the platform, even before the stored copy is deleted.
